## Ideas (captured, not yet developed)

- [[Everyone thinks automation means less work, the teams automating fastest have more of it]] -- (idea · Automation) the more you automate, the more expert human work you create — Dan Shipper, "After Automation"
- [[AI doesn't make you replaceable, it makes everyone the same]] -- (idea · AI) shared models default to sameness ("slop"), so live human judgment is what stays valuable — Dan Shipper, "After Automation"
- [[Your automation isn't set and forget, every agent needs a human on both ends]] -- (idea · Automation) the human sandwich: a human frames the task and judges the result — Dan Shipper, "After Automation"
- [[Your years of expertise are one file away from being a product]] -- (idea · AI) anyone's subject-matter expertise can be packaged into a Claude skill (a markdown file) and sold — Ryan Dozer, TKO Pod
- [[The best digital product to sell is the tool you built for yourself]] -- (idea · AI) dogfooding: build skills for your own daily work, then package and sell the same stack — Ryan Dozer, TKO Pod
- [[Stop Feeding AI PDFs - Markdown Is Its Native Format]] -- (idea · AI) models read markdown/plain text more reliably than PDFs, so format choice changes accuracy — Ryan Dozer, TKO Pod
- [[Don't tell Claude to make a skill - use the skill that makes skills]] -- (idea · AI) use Anthropic's free skill-creator skill (best practices baked in) instead of cold-prompting — Ryan Dozer, TKO Pod
- [[Building a Claude skill is a voice note and one sentence]] -- (idea · AI) the whole creation process is a phone voice brain-dump + "use the skill creator skill" — Ryan Dozer, TKO Pod
- [[Build a Claude skill that rewrites itself when it's wrong]] -- (idea · Automation) skills update in real time; correct once and it never repeats, even auto-updating in the background — Ryan Dozer, TKO Pod
